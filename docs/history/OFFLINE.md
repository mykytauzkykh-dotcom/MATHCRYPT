# Offline launch
Double-click `index.html` (any modern browser). No installation or internet is needed: the code is in one file. Without internet the Google Fonts stylesheet and the decorative three.js script are simply skipped.
Data is kept in the browser profile (localStorage, IndexedDB) separately for `file://` and for each web address. Use "Data & Backups" to export/restore.
Not available: Service Worker / PWA installation (not implemented in this stage; also unsupported under `file://`).

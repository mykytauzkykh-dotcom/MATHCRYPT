# MATHCRYPT 6.0 — Stage 3c

Нове: **Панель** (стартова вкладка), **Карта дисциплін** (граф знань), **Режим захисту 2.0**, **PWA** (manifest, Service Worker, іконки). Усі попередні функції та дані збережено.

## Що реально перевірено (лише Chromium 153 через Playwright; Firefox і WebKit у середовищі відсутні)
- Вбудовані тести: **232/232** (218 попередніх + 14 нових без дублювання: цілісність графа, BFS, пошук, лічильники, підсумок тестів, захист — час/нотатки/експорт/RSA, PWA).
- Дублікатів id немає; помилок JS у консолі немає; на 390 px горизонтального прокручування немає.
- Реальний офлайн: через локальний http-сервер зареєстровано Service Worker, після `setOffline` сторінка перезавантажилась, обчислення та всі 232 тести пройшли без мережі.
- Клацання інтерфейсом: граф (вибір, пошук, шлях, масштаб, перехід до інструмента), панель (обране, пошук), захист 2.0 (слайди, демо Діофанта/Сміта/RSA/LLL, експеримент B наживо, таймер, нотатки, автономна копія).

## Опис
- **Панель:** лічильники реальні (localStorage `mc6_stats`, `mc6_tests`). «Запуски обчислень» = натискання основних кнопок у вкладках інструментів. Лічильники ведуться з моменту оновлення; запуск тестів їх не змінює. Тести — підсумок останнього запуску.
- **Карта дисциплін:** 14 вузлів, 21 підписане ребро; кожен вузол відкриває реальну вкладку. Масштаб (колесо/кнопки/+−), переміщення (перетягування/стрілки), пошук, найкоротший зв’язок.
- **Захист 2.0:** 7 хв (420 с) з бюджетом на слайд, нотатки, F — повний екран, ←/→/1–8, T/N/R, автономна HTML-копія, режим 5.0 збережено. Тексти актуальності/мети/завдань/новизни/висновків програма **не вигадує**: беруться з Центру публікацій або це порожні поля для автора.
- **PWA:** `index.html` + `manifest.webmanifest` + `sw.js` + `icon-192.png` + `icon-512.png`. З диска (`file://`) Service Worker браузер не дозволяє — сайт працює як звичайний файл. Якщо завантажити лише `index.html`, усе працює, просто без установки.

## Netlify
Завантажте **усю папку `netlify/`** (5 файлів) через Deploys → drag & drop. Після першого відкриття сайт працює без мережі; кнопка «Встановити як застосунок» з’являється у вкладці «Дані та копії» (залежить від браузера).
